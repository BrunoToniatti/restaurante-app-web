# RESTAURANTES [restaurant]
`A tabela de restaurante serve para salvar os restaurantes criado pelos gerentes dos restaurantes`

## Colunas
- ID: Id único para cada restaurante, também pode ser utilizado como matricula
- CNPJ: O CNPJ não precisa ser único, porque o restaurante pode ser uma filial
- MANAGER_ID: Chave estrangeira vindo de usuários_restaurante
- CONTACT_PHONE: Telefone de contato do restaurante.
- NAME: Nome do restaurante
- ADDRESS: Endereço do restaurante.
- SITE: Site do restaurante se tiver
- INSTAGRAM: Instagram do restaurante se tiver
- PATH_LOGO: Endereço da logo dentro do servidor
