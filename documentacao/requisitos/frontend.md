# FRONT-END
O front-end vai ser dividido em duas linguagens `ANGULAR - WEB` e `REACT NATIVE - MOBILE`.

## Angular
`O Angular precisa ser separado certinho em componentes e componentes que precisam ser reaproveitados para ficar evitando formulário diferente e loaders diferentes e tals, então seria legal manter um padrão`
OBS: Utilizar `Angular Material`

## React Native
`Para o React Native seguir a mesma estratégia de manter componentes para evitar layouts diferentes`
