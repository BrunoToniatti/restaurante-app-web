# USUÁRIOS DO APLICATIVO [user_app]
`Tabela de clientes é onde a tabela que será usada no aplicativo, para clientes que buscam restaurantes`

## Colunas

- ID: id único do usuário, pode ser usado como matricula dentro da plataforma
- FIRST_NAME: primeiro nome do usuário
- LAST_NAME: sobrenome do usuário
- PHONE_NUMBER: número de telefone
- PATH_PHOTO: caminho da foto de perfil que o usuário vai tirar
- PASSWORD: senha
- LAST_LOGIN: último registro de login
- EMAIL: email de contato
- USERNAME: nome de usuário
